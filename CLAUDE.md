# Project Context & Coding Guidelines

## Build & Test Commands
- Run tests: `npm test` or `cargo test`
- Typecheck: `npm run typecheck` or `cargo check`
- Lint/Format: `npm run lint`

## Strict Rules
- Always run the relevant test suite before proposing/finishing a task.
- Do not add comments explaining obvious code.
- Prefer explicit typings over implicit `any`.
- Keep modifications scoped strictly to the requested feature/bugfix.
